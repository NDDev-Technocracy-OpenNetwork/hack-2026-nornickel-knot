HARMONIC LABS · РЕЗУЛЬТАТ
Архитектура

Пайплайн: от сырых файлов до ответа

Парсинг + OCRPDF / DOCX / PPTX / XLS. Текстовый слой постранично; сканы — EasyOCR на GPU. Кириллица чинится, шум помечается.
Извлечение фактовQwen2.5-7B на H100 (vLLM, continuous batching). 10 GPU параллельно: 23 511 чанков за один прогон, ~47 тыс. токенов/с суммарно.
Граф знанийДедупликация узлов по канонич. имени (RU и EN сливаются в один узел). Каждая связь несёт число, единицу, условие, страницу.
Гибридный ретривHarmonic-эмбеддинги документов + сущностный поиск по графу. 2-hop раскрытие окрестности. 1.8 с, целиком на CPU.
Синтез ответаYandexGPT (API из РФ — официальный стек). Отвечает только по фактам графа, каждое утверждение — с источником.

Экспорт в Neo4j — полный контракт данных (documents / chunks / entities / mentions / relations) для промышленной графовой СУБД.

Ключевое отличие

Harmonic — наша собственная нейросеть

Может, у вас там свои видеокарты под столом, вы дообучите какую-нибудь свою нейронку... Это будет вообще очень круто. — эксперт трека, Q&A-сессия (в шутку). Мы сделали это всерьёз.

Опубликованная архитектура

Иерархическая SSM-модель (state space model) собственной разработки — научная статья опубликована и замечена независимыми исследователями.

Обучена на корпусе задачи

270 МБ текстов горной металлургии. Перплексия на валидации улучшена с 24.5 до 19.9 за ночь дообучения на H100.

Читает документ целиком

Один проход — один вектор документа. Ретрив всего корпуса на обычном CPU, без GPU и без тяжёлых embedding-моделей в проде.
HARMONIC LABS · СОБСТВЕННАЯ МОДЕЛЬ
Достоверность

Система не выдумывает —
и это проверяемо

Каждый факт — со страницей

Ответ собирается только из фактов графа. У каждого — файл-источник и диапазон страниц: верифицируемость по первоисточнику, как просили эксперты.

Белые пятна — как фича

«Где мы ещё не копали» — система прямо говорит, каких данных нет, вместо правдоподобной выдумки. На контрольных вопросах жюри честно разделяет: вот что есть, вот чего не хватает.

Детектор противоречий

Механическая сверка чисел между источниками: одна пара сущностей, одна единица измерения, сопоставимые условия. Разные условия эксперимента — не противоречие.

Честный результат на текущем корпусе: явных числовых противоречий не найдено — редкие пересечения источников по одной точной паре сущностей. Механизм готов и сработает по мере роста базы.

HARMONIC LABS · ЧЕСТНОСТЬ
Интерфейс

Живой граф,
а не консоль

Обзор графа как в Obsidian

Интерактивная карта корпуса: фильтры по 8 типам сущностей, текстовый поиск по узлам, силовая укладка, zoom, pan, перетаскивание узлов. Нейро-режим: Harmonic находит смысловые затравки по запросу — граф собирается вокруг смысла, а не по точному совпадению слов.

Свой документ — в граф за минуту

Кнопка «Добавить свой PDF»: парсинг, извлечение той же онтологией через YandexGPT, слияние с живым графом без перезапуска, пересчёт Harmonic-эмбеддинга.

Карта связей под каждым ответом

К каждому ответу рисуется подграф использованных фактов — видно, через какие узлы связаны источники, и почему система ответила именно так.

Многопараметрические запросы

Материал + процесс + условия + числа в одном вопросе естественным языком — требование задания закрыто гибридным ретривом по типизированному графу.

Neo4j-подобная навигация

Приближение колесом, перемещение камеры фоном, выделение соседей при наведении, возврат графа в кадр двойным кликом.

Поиск без подготовки

Исследователь формулирует вопрос обычным языком, а не пишет Cypher-запросы и не ищет вручную по архивным папкам.
HARMONIC LABS · ИНТЕРФЕЙС
Ресурсооптимальность

Считали деньги,
а не только качество

7B вместо 32B

Замерили на своих данных: Qwen2.5-7B даёт в 3.8 раза больше валидных фактов в единицу времени, чем 32B. Выбор по метрике, не по моде.

Ретрив без GPU

Harmonic — компактная модель: эмбеддинг документа и поиск по 1114 документам работают на CPU. В проде GPU нужен только на этапе загрузки новых архивов.

Официальный стек РФ

Синтез ответов — YandexGPT по выданным ключам. Открытый стек: vLLM, Qwen, networkx, FastAPI, PyTorch. Всё воспроизводимо, ни одной проприетарной «чёрной коробки».
