Вопрос на естественном языке — структурированный ответ за 4 секунды, с числами, условиями и ссылкой на страницу первоисточника. Поверх 90-летнего архива компании, обработанного собственным пайплайном извлечения фактов.

Архитектура

Пайплайн: от файлов до ответа

Парсинг + OCRPDF/DOCX/PPTX/XLS. Текстовый слой постранично; сканы — EasyOCR на GPU.
Извлечение фактовQwen2.5-7B на H100 (vLLM). 10 GPU параллельно, 23511 чанков за прогон.
Граф знанийДедупликация по канонич. имени. Связь несёт число, единицу, условие, страницу.
Гибридный ретривHarmonic-эмбеддинги + сущностный поиск. 2-hop, 1.8с, целиком CPU.
Синтез ответаYandexGPT (РФ — офиц. стек). Только факты графа, с источником.

Экспорт в Neo4j — полный контракт данных (documents / chunks / entities / mentions / relations) для промышленной графовой СУБД.

Факт — со страницей

Ответ собирается только из фактов графа. У каждого — файл-источник и диапазон страниц.

Белые пятна — как фича

«Где мы ещё не копали» — система прямо говорит, каких данных нет, вместо выдумки.

Детектор противоречий

Механическая сверка чисел: одна пара сущностей, одна единица, сопоставимые условия.
